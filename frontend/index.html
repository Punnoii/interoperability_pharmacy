Mapping Assistant

This prototype will help users inspect source tables, choose IDMP-O mapping templates, preview generated triples, and send confirmed mappings to the VKG runtime.

Core Workflow

Step Purpose
Source profiling Read columns, datatypes, null rates, and sample values from Trino.
Template suggestion Suggest safe IDMP-O mapping patterns such as identifier, name, package, or ingredient.
Human confirmation Let the user accept, edit, or reject each mapping suggestion.
VKG preview Generate OBDA and preview the resulting triples through Ontop.
