## How To Read This File

- `Class`: a concept/type in the ontology, such as `Substance` or `SubstanceName`.
- `ObjectProperty`: links one resource to another resource, such as `hasSubstanceName`.
- `DatatypeProperty`: links a resource to a literal value, such as a string or number.
- `NamedIndividual`: a controlled vocabulary value, such as `SubstanceTypeClassifier-Chemical`.
- `subClassOf`, `domain`, `range`, and restrictions are hints for how the concept is meant to be used; OWL itself is open-world, so validation still needs a profile or SHACL.
